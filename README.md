# AI-Powered Customer Retention & Churn Analytics Platform

## Overview

This project predicts customer churn using Machine Learning and provides business-focused analytics to help organizations reduce customer attrition.

## Features

- Customer Churn Prediction using Logistic Regression
- Interactive Data Visualization
- Customer Risk Segmentation
- Revenue at Risk Analysis
- Top Customers to Save
- Churn Heatmap Analysis
- Retention Strategy Simulator
- Executive Business Insights

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Plotly
- Matplotlib
- Seaborn
- Jupyter Notebook

## Business Impact

The dashboard not only predicts churn but also estimates revenue at risk, identifies high-risk customers, and recommends retention opportunities.

## Key Insights

- Geography-wise churn analysis
- Customer age segmentation
- Credit score analysis
- Feature importance analysis
- Revenue impact estimation
